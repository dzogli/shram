# Шрам — броненосец Проклятой чащи

Платформер про броненосца-громилу: Проклятая чаща, склепы, арена Владыки, Австралия и Антарктида.

Вся игра — один файл `index.html`. Ей не нужен сервер, и после первого запуска она работает без интернета.

## Как выложить на GitHub

1. Создай на github.com новый репозиторий (например, `shram`).
2. Загрузи туда **все файлы из этого архива вместе с папками** `icons` и `.github`
   (кнопка *Add file → Upload files*, перетащи содержимое папки).
3. Открой *Settings → Pages* и в пункте *Source* выбери **GitHub Actions**.
   > Если папка `.github` не загрузилась (на некоторых компьютерах она скрыта): *Add file → Create new file*, в имени файла напиши `.github/workflows/build.yml` и вставь туда содержимое этого файла из архива.
4. Открой вкладку *Actions*: там автоматически запустится «Сборка игры». Подожди, пока все шаги станут зелёными (около 5–10 минут).

## Где взять игру после сборки

| Устройство | Как получить |
|---|---|
| **Браузер (любой)** | Ссылка вида `https://ИМЯ.github.io/shram/` — её показывает шаг *pages* в Actions |
| **Android** | *Actions* → последний запуск → внизу *Artifacts* → **Shram-Android-APK** → скачать, распаковать, установить `Shram.apk` (разреши установку из неизвестных источников) |
| **Windows** | Там же → **Shram-Windows** → `Shram-Windows.exe`, запускается без установки |
| **iPhone / iPad** | Открой ссылку на игру в **Safari** → кнопка «Поделиться» → **«На экран Домой»**. Появится иконка, игра откроется на весь экран и будет работать офлайн |
| **ПК как приложение** | Открой ссылку в Chrome или Edge → значок установки в адресной строке → «Установить» |

### Релиз с файлами
Чтобы APK и EXE лежали в разделе *Releases*: *Releases → Draft a new release*, тег `v1.0`, опубликовать. Сборка сама приложит оба файла.

## Управление
- Телефон: кнопки на экране (игра сама переворачивается горизонтально).
- Клавиатура: ← → бег, ↑ / пробел — прыжок (в воздухе — двойной), ↓ — шар, Shift — нора, F — огонь, G — кувалда, K — кулак (с рукой демона), P — пауза, M — звук.
- Чит-коды в меню: `GOD` — неуязвимость, `DEV` — режим разработчика.
